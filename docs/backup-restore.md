# نسخ SQLite الاحتياطي والاستعادة

## إنشاء نسخة

تأكد من أن DATABASE_URL يشير إلى SQLite ثم نفّذ:

    npm run db:backup -- backups/athar-2026-09-12.db

ينشئ الأمر ملف قاعدة مستقلًا وملف checksum باسم sha256، ولا يستبدل نسخة موجودة.

## التحقق من النسخة

    npm run db:backup:verify -- backups/athar-2026-09-12.db

يتحقق الأمر من سلامة SQLite ومن وجود جدول المدارس في نسخة مؤقتة ثم يحذف النسخة المؤقتة.

## الاستعادة

1. أوقف التطبيق.
2. احتفظ بنسخة من الملف الحالي.
3. انسخ النسخة الاحتياطية إلى مسار قاعدة البيانات المحدد في DATABASE_URL.
4. شغّل npm run db:migrate:deploy.
5. شغّل التطبيق وتحقق من /api/health/readiness.

أوقف التطبيق أثناء النسخ والاستعادة. احتفظ بالنسخ خارج المستودع وبصلاحيات وصول محدودة. SQLite مناسب لخادم واحد؛ للتوسع الأفقي أو الكتابة المتزامنة العالية انقل قاعدة البيانات إلى PostgreSQL.
