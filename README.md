# أثر | ATHAR

منصة سعودية لقياس أثر التدريب المدرسي، من البيانات إلى القرار.

## التشغيل المحلي

```bash
npm ci
Copy-Item .env.example .env
npm run setup:dev
npm run db:generate
npm run db:migrate:deploy
npm run dev
```

يمكن تشغيل بيانات العرض في التطوير فقط بوضع `ATHAR_SEED=true` ثم تنفيذ `npm run db:seed`.

## الدخول

- المدير: يسجل أو يدخل بالبريد الإلكتروني أو الجوال وكلمة المرور.
- المنسوب: يدخل برقم الهوية فقط، بلا رسالة SMS أو بريد أو CAPTCHA.

## لوحة الإدارة الداخلية وأكواد الرخص

اضبط في بيئة السيرفر فقط:

```env
ATHAR_ADMIN_PATH="مسار-داخلي-طويل-وعشوائي"
ATHAR_ADMIN_SECRET="رمز-سري-طويل-لا-يظهر-للمستخدمين"
```

بعد التشغيل افتح:

```text
https://your-domain.com/admin/<ATHAR_ADMIN_PATH>
```

تتيح اللوحة متابعة الإحصاءات العامة والأنشطة المبهمة وإنشاء أكواد رخصة لمرة واحدة. يظهر الكود كاملًا عند إنشائه فقط، ويُحفظ في قاعدة البيانات على شكل hash. عند استخدامه أثناء التسجيل يُستهلك داخل transaction، ويُخصم مقعد تلقائيًا من عرض الإطلاق.

`ATHAR_LICENSE_CODES` مخصص للتطوير والاختبارات فقط؛ في الإنتاج أنشئ الأكواد من لوحة الإدارة حتى يُحتسب استهلاك المقاعد بصورة صحيحة.

توجد محددات معدل وسجل تدقيق للأحداث الأمنية، لكن دخول المنسوب برقم الهوية وحده أقل قوة من التحقق الثنائي. شغّل الإنتاج خلف HTTPS مع Redis لمحددات المعدل.
